# Python-Insurance-Data-Analysis
# 📊 Insurance Portfolio Data Analysis (Python)

Bu layihə sığorta portfeli üzrə verilənlərin təmizlənməsi, analizi və vizuallaşdırılması məqsədilə Python dilində işlənib hazırlanmışdır.

---

## 🛠️ İstifadə Olunan Kitabxanalar və Alətlər
* *Data Manipulation & Analysis:* Pandas, NumPy
* *Data Visualization:* Seaborn, Matplotlib
* *Mühit:* Jupyter Notebook / Python

---

## 🔍 Əsas Analitik Proseslər və Mərhələlər
1. *Data Cleaning (Verilənlərin Təmizlənməsi):* Sığorta məlumatlarındakı çatışmayan dəyərlərin (missing values) təmizlənməsi və formatlanması.
2. *Data Merging (Birləşdirmə):* Left Join əməliyyatları vasitəsilə fərqli mənbələrdən gələn məlumat dəstlərinin vahid strukturda birləşdirilməsi.
3. *KPI Calculations:* Portfel üzrə əsas effektivlik göstəricilərinin və maliyyə KPI-larının hesablanması.
4. *Outlier Detection:* IQR (Interquartile Range) üsulu ilə məlumatlardakı kənar kəskin rəqəmlərin (outliers) aşkarlanması.
5. *Correlation Heatmaps:* Dəyişənlər arasındakı əlaqələri analiz etmək üçün korrelyasiya istilik xəritələrinin vizuallaşdırılması.
